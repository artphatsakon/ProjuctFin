# ระบบติดตามและพยากรณ์ราคาทองคำและน้ำมันดิบ

เว็บไซต์แสดงราคาปัจจุบัน ราคาย้อนหลัง และผลพยากรณ์ล่วงหน้า 7 วัน จากโมเดล Prophet, GRU และ XGBoost

## ติดตั้งและรัน
```
pip install -r requirements.txt
streamlit run app.py
```
เปิด http://localhost:8501 (เว็บเขียนด้วย Streamlit — Python ล้วน)

- **ผู้ใช้ทั่วไป:** ดูราคา กราฟ ผลพยากรณ์ และความแม่นยำของโมเดลได้ทันที ไม่ต้องเข้าสู่ระบบ
- **ผู้ดูแลระบบ:** เมนู "ผู้ดูแลระบบ" ทางซ้าย หรือ http://localhost:8501/admin
  - ชื่อผู้ใช้ `admin` รหัสผ่านเริ่มต้น `admin1234` **(เปลี่ยนรหัสผ่านทันทีในหน้าตั้งค่า)**
  - สั่งฝึกสอนโมเดลใหม่ อัปเดตข้อมูล แก้ไข/เพิ่ม/ลบข้อมูลราคาในตาราง ตั้งค่า API (อัตราแลกเปลี่ยนสำรอง, รหัสผ่าน)

## แหล่งข้อมูล
- **Yahoo Finance** (ผ่านไลบรารี yfinance ไม่ต้องสมัคร key): ราคาปัจจุบันและข้อมูลย้อนหลัง 15 ปีของทองคำ (GC=F) และน้ำมันดิบ WTI (CL=F) รวมถึงอัตราแลกเปลี่ยน USD/THB (THB=X)
- ถ้าดึงข้อมูลออนไลน์ไม่ได้ ระบบจะใช้ราคาปิดล่าสุดในไฟล์ CSV แทน

## การพยากรณ์และการวัดผล
- เมื่อผู้ใช้เปิดหน้าเว็บ ระบบโหลดไฟล์โมเดลที่ฝึกไว้แล้วจาก `MODEL/` แล้วพยากรณ์ 7 วันทำการต่อจากราคาล่าสุด โดยไม่ต้องฝึกใหม่
- ความแม่นยำ (MAE, RMSE, MAPE, Accuracy = 100 − MAPE) วัดแบบเดียวกันทุกโมเดล คือพยากรณ์ล่วงหน้า 7 วันซ้ำหลายจุดในชุดทดสอบ 1 ปีล่าสุด และเทียบกับ Naive (เดาว่าราคาเท่าราคาล่าสุด)
- ขั้นตอนแนะนำเมื่อจะใช้ข้อมูลใหม่: Admin → อัปเดตจาก Yahoo Finance → เทรนใหม่ทั้งหมด

## เปิดเว็บออนไลน์ 24 ชม. + ดึงข้อมูลทุกเที่ยงคืน (Windows)
ทำครั้งเดียว: คลิกขวา `setup_autostart.bat` → **Run as administrator** สคริปต์จะ
1. ติดตั้ง cloudflared (ถ้ายังไม่มี)
2. ตั้ง Task Scheduler: ดึงข้อมูลจาก Yahoo ทุกวัน 00:00 · เปิดเว็บ + ลิงก์ออนไลน์เองทุกครั้งที่เข้าสู่ระบบ Windows
3. ปิดโหมด Sleep/Hibernate ตอนเสียบปลั๊ก
4. แสดงลิงก์เว็บออนไลน์ (รูปแบบ `https://xxxx.trycloudflare.com`)

| ไฟล์ | หน้าที่ |
|---|---|
| `start_web.bat` | เปิดเว็บที่พอร์ต 8501 (เปิดใหม่เองถ้าหยุด) — log: `web_log.txt` |
| `start_tunnel.bat` | เปิดลิงก์ออนไลน์ Cloudflare Tunnel — log: `tunnel_log.txt` |
| `show_url.bat` | ดูลิงก์เว็บออนไลน์ปัจจุบัน |
| `update_data.bat` | ดึงข้อมูลล่าสุด (Task Scheduler เรียกทุกเที่ยงคืน) — log: `update_log.txt` |
| `remove_autostart.bat` | ยกเลิกการทำงานอัตโนมัติทั้งหมด |

ข้อควรรู้: ลิงก์ trycloudflare.com จะเปลี่ยนทุกครั้งที่รีสตาร์ทเครื่อง (ดูลิงก์ใหม่ด้วย `show_url.bat`) · เครื่องต้องเปิดและเข้าสู่ระบบ Windows ไว้ตลอด · ผู้ดูแลต้องตั้งรหัสผ่าน Admin ใหม่ก่อนใช้งานครั้งแรก

## Deploy ฟรีบน Streamlit Community Cloud (ไม่ต้องเปิดเครื่องทิ้งไว้)
1. **อัปโหลดโปรเจกต์ขึ้น GitHub** — ติดตั้ง GitHub Desktop → File → Add local repository → เลือกโฟลเดอร์นี้ → Publish repository
   (`.gitignore` กันไม่ให้อัปโหลด `.venv`, `config.json`, ไฟล์ log และโฟลเดอร์ Flask เก่า)
2. **สร้างเว็บ** — เข้า share.streamlit.io → Sign in with GitHub → Create app → เลือก repo, branch `main`, ไฟล์ `app.py`
   → Advanced settings: Python **3.12** และใส่ Secrets:
   ```
   ADMIN_USER = "admin"
   ADMIN_PASSWORD = "ตั้งรหัสที่ยากเดา"
   ```
   → Deploy (ครั้งแรกใช้เวลาหลายนาทีเพราะติดตั้ง tensorflow/prophet)
3. **ดึงข้อมูลทุกเที่ยงคืน** — ไฟล์ `.github/workflows/update-data.yml` ให้ GitHub Actions รัน `update_data.py` ทุกวัน 00:00 (เวลาไทย)
   แล้วบันทึก CSV ใหม่ลง repo เว็บจะใช้ข้อมูลใหม่เอง · ครั้งแรกให้เข้า repo → แท็บ Actions → เปิดใช้ → กด Run workflow ทดสอบ

ข้อจำกัดของแบบฟรี: RAM ประมาณ 2.7 GB · เว็บหลับเมื่อไม่มีคนเข้า 12 ชม. (คนแรกที่เข้าต้องกดปลุกและรอประมาณ 1 นาที) ·
การแก้ข้อมูล/เทรนโมเดลผ่านหน้า Admin บนคลาวด์ไม่ถาวร (หายเมื่อเว็บรีสตาร์ท) — ถ้าจะเทรนใหม่ ให้เทรนในเครื่องแล้วอัปโหลดโฟลเดอร์ `MODEL` ขึ้น GitHub
